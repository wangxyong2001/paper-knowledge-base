## 二、阶段详情

### 阶段1: 检索专家 (PaperRetrievalAgent)

**输入**:
- query: "Transformer自注意力机制的核心创新是什么?"
- top_k: 5

**处理**:
- VectorSearch: 向量语义检索
- BM25Search: 关键词匹配
- RRF融合: Reciprocal Rank Fusion

**输出**:
| 指标 | 值 | 说明 |
|-----|-----|------|
| 召回数量 | 5 | 达标(>=3) |
| 平均评分 | 0.85 | 高质量 |
| 覆盖率 | 80% | 覆盖核心内容 |
| 向量检索数 | 5 | 正常 |
| BM25检索数 | 5 | 正常 |

**质量判定**: ✓ 召回率达标

---

### 阶段2: 解读专家 (PaperAnalysisAgent)

**输入**:
- chunks: 5个文档片段

**处理**:
- 公式提取: LaTeX/编号公式识别
- 概念提取: 术语识别+过滤
- 摘要生成: 餐巾纸摘要

**输出**:
| 输出项 | 值 | 说明 |
|-----|-----|------|
| 摘要长度 | 150字符 | 简洁准确 |
| 核心概念 | 4个 | Self-Attention, Multi-Head, Position Encoding, LayerNorm |
| 公式提取 | 2个 | Attention公式, MultiHead公式 |
| 代码设计 | 存在 | transformer_block.py |

**质量判定**: ✓ 分析完整

---

### 阶段3: 质量专家 (QualityAssuranceAgent)

**输入**:
- output: 分析结果文本
- chunks: 5个支撑片段

**处理**:
- 幻觉检测: 实体匹配+支撑率计算
- 引用验证: chunk_id溯源
- 支撑度评估: 内容覆盖率

**输出**:
| 指标 | 值 | 说明 |
|-----|-----|------|
| 质量评分 | 0.92 | 高质量 |
| 幻觉风险 | low | 无明显幻觉 |
| 引用准确率 | 95% | 准确溯源 |
| 支撑率 | 88% | 内容有支撑 |
| 通过状态 | True | 验证通过 |

**质量判定**: ✓ 验证通过

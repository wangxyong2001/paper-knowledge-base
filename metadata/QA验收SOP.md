## 3. 验收测试流程

### 3.1 单元测试阶段

```
步骤1: 环境准备
├── 激活虚拟环境: source .venv/bin/activate
├── 检查依赖: pip list
└── 初始化数据库: python -c "from database.schema import init_database; init_database()"

步骤2: 核心模块测试
├── 测试工具注册: python tests/test_tool_registry.py
├── 测试记忆管理: python tests/test_memory_manager.py
└── 覆盖率检查: coverage run tests/*.py

步骤3: 质量门禁
├── 单元测试通过率 ≥ 95%
├── 关键模块覆盖率 ≥ 80%
└── 无阻断性错误
```

### 3.2 集成测试阶段

```
步骤1: 完整流程测试
└── python tests/integration_test.py

步骤2: API集成测试
├── 测试DashScope客户端
├── 测试响应时间监控
└── 测试SLA检查

步骤3: 端到端验证
├── 检索流程: 关键词 → 向量检索 → BM25 → RRF融合
├── 生成流程: Prompt组装 → LLM调用 → 输出格式化
└── 审计流程: 全事件记录 → 质量指标 → Dashboard
```

### 3.3 性能测试阶段（如需要）

```
步骤1: 响应时间测试
├── 单次请求延迟
├── 并发请求延迟
└── P50/P95/P99统计

步骤2: 压力测试
├── 10并发请求
├── 50并发请求
└── 错误率监控

步骤3: 容量测试
├── 1000条检索
├── 10000条检索
└── 数据库性能
```

## 5. 问题处理流程

### 5.1 Bug生命周期

```
New → Assigned → In Progress → Fixed → Verified → Closed
                ↓
             Reopened (如果验证失败)
```

### 5.2 问题分类

| 优先级 | 定义 | 响应时间 | 解决时间 |
|--------|------|----------|----------|
| P0 | 阻断性问题，无法进行验收 | 立即 | 1小时 |
| P1 | 功能严重缺陷 | 2小时 | 4小时 |
| P2 | 功能轻微缺陷 | 1天 | 3天 |
| P3 | 优化建议 | 3天 | 1周 |

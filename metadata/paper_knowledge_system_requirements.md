# 论文知识库系统需求描述

> 一页纸概述：解决的问题、核心价值、透明治理

---

## 一、解决的问题

| 痛点 | 具体表现 | 解决方案 |
|-----|---------|---------|
| **知识散落** | 87+论文分散在硬盘各处，检索需人工翻阅 | 向量化存储 + 语义检索，秒级定位 |
| **理解门槛** | 公式晦涩、英文术语多，耗时3-5小时/篇 | 自动通俗化解读 + 公式餐巾纸摘要 |
| **信任缺失** | LLM输出无来源，无法验证真实性 | 每句话标注出处，Citation追溯原文 |
| **遗忘循环** | 上周分析的论文，下周问同样问题需重新检索 | 记忆系统存储分析历史，跨会话复用 |
| **成本黑洞** | API调用无记录，月底发现账单超支 | Token级成本审计，实时预算监控 |
| **安全盲区** | 输入可能被注入攻击，Prompt模板随意修改 | 5类注入检测 + CalVer模板版本控制 |

## 二、核心价值

### 用户可感知变化

| 指标 | 现状 | 目标 | 验证方式 |
|-----|-----|-----|---------|
| 论文定位速度 | 30分钟人工翻阅 | **10秒语义检索** | 实际检索测试 |
| 公式理解时间 | 2小时查资料 | **5分钟餐巾纸摘要** | 用户实测反馈 |
| 知识复用率 | 0%（每次重新分析） | **70%跨会话复用** | 记忆系统命中率 |
| 输出可信度 | 无来源标注 | **100%引用溯源** | Citation检查 |
| 成本可控性 | 月底惊喜账单 | **实时预算预警** | Dashboard监控 |
| 安全透明性 | 黑盒LLM调用 | **全链路审计日志** | SQLite查询 |

## 三、透明治理架构

```
┌─────────────────────────────────────────────────────────────┐
│                     全流程透明化                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  用户输入 ──▶ [注入检测] ──▶ [Prompt模板化] ──▶ LLM调用      │
│      │           │              │               │            │
│      └───────────┴──────────────┴───────────────┘            │
│                    ↓                                        │
│              [审计日志SQLite]                               │
│                    ↓                                        │
│  LLM输出 ──▶ [幻觉检测] ──▶ [引用验证] ──▶ 格式化输出       │
│      │           │              │               │            │
│      └───────────┴──────────────┴───────────────┘            │
│                    ↓                                        │
│              [30+指标采集] ──▶ Dashboard可视化               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 三大透明机制

| 机制 | 存储 | 内容 | 查询方式 |
|-----|------|------|---------|
| **审计日志** | SQLite 14表 | 输入/Prompt/LLM调用/输出全记录 | SQL查询导出 |
| **记忆系统** | Working/Episodic/Semantic三层 | 分析历史、关键概念、跨会话上下文 | Agent自动检索 |
| **Prompt模板** | CalVer版本字典 | rag_query_v2025.12.01等模板 | 版本切换回滚 |

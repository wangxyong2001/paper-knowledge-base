## 四、纠正措施 (Corrective Action)

### 修复代码设计

```python
class SpecializedAgentOrchestrator:
    
    def repair_loop(self, output: str, chunks: List[Dict], max_retries: int = 3) -> Dict:
        """修缮闭环"""
        
        for attempt in range(max_retries):
            # 1. 审核
            review_result = self.qa_agent.compare_with_source(output, chunks)
            
            if review_result["is_passed"]:
                return {"output": output, "status": "passed", "attempts": attempt}
            
            # 2. 修缮（LLM修复）
            repair_prompt = f"""
            原输出存在问题:
            {review_result["issues"]}
            
            请根据论文原文修正:
            {self._assemble_context(chunks)}
            
            确保输出与论文一致，不添加虚假信息。
            """
            
            output = self.llm_client.chat(repair_prompt)
            
            # 3. 审计记录
            self.audit.log_repair_attempt(
                attempt=attempt,
                issues=review_result["issues"],
                repaired_output=output
            )
        
        # 熔断：超过最大重试
        return {
            "output": output,
            "status": "fused",
            "warning": "无法完全修正，请人工审核",
            "attempts": max_retries
        }
```
